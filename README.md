Hospital Management System.
Built console application for managing hospital records (doctors, nurses, patients)with full CRUD operations on a PostgreSQLdatabase by using JDBC
Applied OOP principles: abstract class, inheritance, interfaces, polymorphism and a custom exception for input validation
Implemented search by name, doctor specialization and age range using parameterized SQL queries (PreparedStatement)
Structured the code with a DAO layer, separating database logic from the user menu.
